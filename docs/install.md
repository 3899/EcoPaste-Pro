# 安装与配置指南

EcoPaste-Pro 专为 **Windows** 平台打造，基于 Tauri v2 底座深度结合 Win32 原生 API，具备极低资源占用、瞬时无感呼出与原生级系统融合度。本文档将指导您在 Windows 系统上完成安装部署、常用功能设定与快捷键方案配置。

---

## 📥 下载与安装

前往项目的 [Releases 页面](https://github.com/3899/EcoPaste-Pro/releases/latest) 下载适用于 Windows 的最新构建程序包。

### 系统运行要求
- **操作系统**：Windows 10 (1809 及以上版本) / Windows 11
- **系统架构**：`x86_64` (64 位)
- **运行组件**：系统需内置或已安装 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/zh-cn/microsoft-edge/webview2/)（Windows 11 及较新版本的 Windows 10 系统已默认内置，无需额外安装）

### 安装包形态选择

| 安装包类型 | 文件命名示例 | 说明 |
| :--- | :--- | :--- |
| **标准安装程序 (推荐)** | `EcoPaste_x.x.x_x64-setup.exe` | 包含桌面快捷方式、开始菜单图标创建与自动更新支持 |
| **MSI 企业部署包** | `EcoPaste_x.x.x_x64_en-US.msi` | 适用于静默安装或通过组策略进行批量分发部署 |
| **免安装便携版** | `EcoPaste_x.x.x_x64_portable.zip` | 解压即可直接运行，适合存放于 U 盘或便携工作目录 |

> [!TIP]
> **开机自启动建议**：首次运行后，建议进入「偏好设置 → 通用设置 → 开机自启动」开启该功能，以便剪贴板随系统开机自动在后台常驻监听。

## ⚙️ 核心与推荐功能配置

### 1. Win+V 全局无缝接管
Windows 原生自带的剪贴板历史常存在呼出迟滞、卡顿、不支持大图/代码高亮及历史条目上限较低的问题。EcoPaste-Pro 提供了完全兼容 Windows 习惯的无缝接管机制：
- **开启入口**：进入「偏好设置 → 快捷键 → 常用操作」，开启「接管 Win+V」开关。
- **运行机制**：无需修改系统注册表或破坏系统文件。应用运行期间，在后台底层自动接管 `Win+V` 组合键；退出应用后，Windows 原生剪贴板功能立即自动恢复，实现零侵入、平滑回退。
- **体验提升**：保留经典键位肌肉记忆的同时，获得毫秒级呼出、12 大类内容智能分类与秒级全文检索。

### 2. 鼠标中键全局快捷控制
无需敲击键盘即可快速检视或粘贴剪贴板历史：
- **开启入口**：进入「偏好设置 → 快捷键 → 鼠标中键设置」。
- **触发方式**：支持「单击中键」或「长按中键」呼出。可灵活调节长按触发毫秒阈值（推荐设置为 250~400ms，有效防范日常使用滚轮时的误触）。
- **防误触与资源释放**：内部包含完整的事件防抖机制，在剪贴板窗口内部操作时不会误收窗口；关闭功能后底层系统钩子自动释放，零系统资源残留。

### 3. 双击修饰键与快捷键录制
- **双击修饰键唤醒**：打破传统多指组合键束缚，支持设置为连续双击 `Ctrl`、`Alt` 或 `Shift` 键呼出剪贴板，操作更顺手。
- **快捷键直观录制**：在快捷键设置面板中点击录制，直接在键盘上按下所需键位即可自动完成识别与绑定；下拉菜单内置了常用推荐键位组合。
- **全局纯文本粘贴**：可绑定独立的全局快捷键（如 `Ctrl+Shift+V`），在任何应用中直接将当前最新剪贴板内容作为纯文本粘贴，自动剔除富文本格式与杂乱样式。

### 4. Windows 不夺焦静默粘贴模式
- **适用场景**：文件批量连续重命名、表格/网页表单多行连续录入等场景。
- **操作体验**：
  - 呼出剪贴板窗口时，当前正在编辑的外部窗口（如资源管理器、Excel、IDE）**始终保持前台主焦点不丢失**。
  - 双击条目后直接模拟按键键入原窗口，剪贴板窗口完成粘贴后自动隐藏。
  - 窗口呼出后按下 `空格键` 即刻激活搜索框，按下 `ESC 键` 极速隐藏退回后台。

## 🔄 升级与卸载

### 平滑升级
- 下载新版本安装包直接覆盖安装即可。
- 系统具备数据库自动升级与向下兼容保护机制，历史剪贴板数据与用户个人偏好设置均会完整保留。

### 完整卸载与数据清理
如需彻底移除应用及所有历史数据：
1. 通过 Windows 系统「设置 → 应用 → 安装的应用」卸载 EcoPaste。
2. 手动清理数据与配置持久化目录：
   - 默认配置与数据库路径：`%APPDATA%\com.ayangweb.ecopaste\`（在文件资源管理器地址栏输入即可跳转）。
   - 若在设置中重定向了图片或数据库存储目录，请同步清理该自定义文件夹。
