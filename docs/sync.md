# 数据同步与移动端指南

EcoPaste-Pro 内置了轻量级、去中心化的**跨设备数据协同链路**与**WebDAV 云端资产备份引擎**。它既能在局域网内与手机（安卓 Tasker / 自动化工具、iOS 快捷指令）实现零延迟剪贴板互通，也可以依托坚果云、NextCloud 等 WebDAV 存储实现多端历史安全备份。

---

## 🌐 跨设备同步网络架构

```text
                  +--------------------------+
                  |  EcoPaste-Pro (PC 客户端) |
                  +-------------+------------+
                                |
        +-----------------------+-----------------------+
        |                                               |
  [局域网 HTTP 接收]                              [主动 Webhook 推送]
  POST /api/write                                携带 JSON Payload
        ^                                               v
        |                                               |
+-------+--------------------+            +-------------+--------------+
| 移动端 / 外部设备 发送剪贴板  |            | 移动端 / 外部设备 接收剪贴板  |
| (Android Tasker / Shortcuts) |            | (手机端 HTTP Server / 监听器) |
+----------------------------+            +----------------------------+
```

## 📡 本地 HTTP 自动接收服务规范

在电脑端开启接收服务后，EcoPaste-Pro 将在后台启动轻量 HTTP 服务器，外部设备可通过标准 REST 请求直接向电脑剪贴板写入数据。

### 1. 服务开启
进入「偏好设置 → 数据同步 → 接收数据」：
- 勾选 **【启用自动接收服务】**。
- 设定监听端口（默认推荐 `41234`）。
- 可选开启 **【接收后自动写入系统剪贴板】**（开启后，接收到的内容将立即可供 `Ctrl+V` 粘贴）。

### 2. 接口定义

- **URL**: `http://<电脑局域网IP>:<端口>/api/write`
- **Method**: `POST`
- **Headers**: `Content-Type: application/json`

#### 请求体示例 (JSON)

```json
{
  "content": "待同步的剪贴板内容",
  "type": "text",
  "device": "Pixel 8 Pro"
}
```

#### 字段说明

| 字段 | 类型 | 必填 | 取值范围与说明 |
| :--- | :--- | :--- | :--- |
| `content` | String | 是 | 剪贴板正文数据（纯文本、HTML 代码、或 Base64 格式图片） |
| `type` | String | 否 | 内容类型：`text` (默认)、`html`、`rtf`、`image`、`files` |
| `device` | String | 否 | 发送端设备标识，EcoPaste 会在历史记录列表中渲染专属的远端设备图标 |

#### 返回响应
```json
{
  "code": 200,
  "message": "success",
  "data": {
    "id": "e0b82f1b-419b-4b20-9118-05eb92318ab1"
  }
}
```

## ♻️ 防同步回环保护机制 (Anti-Loopback)

在双向同步链路中，极易出现**“A设备同步至B设备 → B设备写入系统剪贴板 → B设备监听到剪贴板变更 → 再次将内容推回A设备”**的无限死循环。

EcoPaste-Pro 在底层引入了**传输回写指纹校验算法**：
1. 当本地接收服务将远端数据写入系统剪贴板时，会在内存中为该数据的哈希特征标记临时指纹（Writeback Fingerprint）。
2. 本地剪贴板监听器捕获到变更事件时，优先核对指纹白名单。
3. 若命中指纹，系统将直接认定为“自生性回写事件”，**只入库不触发外部 Webhook 广播**，从根源切断回环死锁。

## 📤 主动推送与图片中转策略

### 1. 推送策略模式
进入「偏好设置 → 数据同步 → 推送数据」，可自由选择触发方式：
- **手动推送**：在历史记录卡片头部或右键菜单中点击「推送」，精准发送单条内容。
- **自动推送 - 仅收藏模式**：当用户为某条条目标星收藏时，系统自动将其静默推送至移动端。
- **自动推送 - 自定义标签模式**：可勾选特定内容类型（如仅推送文本或链接），复制即自动推送。

### 2. 五大图片中转策略
由于图片体积较大，跨设备传输提供了灵活的策略通道：
1. **局域网临时直链**：在 PC 本地临时托管图片，向对端发送局域网 HTTP 下载链接。
2. **Webhook 网关中转**：将图片以 Multipart 或 Base64 编码直接经由网关转发。
3. **WebDAV 中转**：自动将图片上传至 WebDAV 指定目录，对端按需拉取。
4. **本地目录映射**：针对通过网络共享文件夹（Samba / NFS）挂载的设备，直接同步相对路径。
5. **直接拦截**：仅同步文本类内容，忽略或阻断大体积图片传输。

## ☁️ WebDAV 云端备份与任务调度

EcoPaste-Pro 提供了企业级可靠的 WebDAV 资产同步与灾备能力：

- **精简备份 vs 完整备份**：
  - **完整模式 (`full`)**：打包全部元数据、文本内容及本地磁盘缓存的完整图片库。
  - **精简模式 (`lite`)**：仅备份文本记录与关联指纹，剥离超大图片文件，实现极小体积秒级同步。
  - **筛选模式 (`filter` / `favs`)**：支持按类型多选或仅导出星标收藏数据。
- **任务自动化调度引擎**：
  - 支持 **定时模式**（每日指定时刻执行备份）。
  - 支持 **间隔模式**（每隔 N 小时/分钟轮询执行）。
  - 支持 **Cron 表达式**（高阶自由度定制，如 `0 0 2 * * ?` 每日凌晨两点执行）。
- **云端目录自动探测**：内置 `ensure_remote_dir` 递归嗅探机制，云端缺失目标层级目录时自动递归建立，彻底避免 WebDAV `405 Method Not Allowed` 报错。
